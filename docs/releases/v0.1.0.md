Blackbox is a local recorder for one machine. It keeps a searchable timeline of configuration changes, service failures and resource spikes, and `blackbox incident` turns that timeline into a report of what changed before something broke.

**Pre-release.** Suitable for demonstration and controlled trials, not for unattended production use.

### What it does

- Append-only, hash-chained SQLite event store; `blackbox verify` detects edits and mid-history deletions.
- Collectors for tracked config files (redacted diffs), services (`systemd`, `windows`, `tcp`, `command` probes) and CPU, memory and disk spikes.
- Incident reports in HTML, Markdown and JSON.
- Core has no third-party dependencies; `psutil` is optional.

### Known limitations

- Polling, not event hooks: changes reverted between two polls are invisible.
- Tamper evidence, not tamper proofing: removed trailing events are only caught with an external anchor.
- Redaction is pattern-based and can miss unrecognised secret formats.
- Windows and `systemd` service probes are tested against sample output, not live services. Green Windows CI does not validate them.
- No retention: the event table grows without limit, and there has been no long soak run.
- Single machine only. Ordering of events is not causation.

Checksums are in `SHA256SUMS`. See the [changelog](https://github.com/5K-bit/blackbox/blob/v0.1.0/CHANGELOG.md) for details.
